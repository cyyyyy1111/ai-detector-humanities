# AI 内容检测技能（本科人文课程论文专版）

> 基于语言特征与问题意识的综合检测框架，专为历史、哲学、文学、艺术史、社会学等本科人文课程论文设计。不依赖数据库比对，通过大结构判断与7个维度综合评估AI生成痕迹。

## 安装

### 方法一：npx 一键安装（推荐）

```bash
npx skills add https://github.com/你的用户名/ai-detector-humanities.git
```

### 方法二：Git 克隆

```bash
git clone https://github.com/你的用户名/ai-detector-humanities.git ~/.claude/skills/ai-detector-humanities
```

### 方法三：手动安装

1. 下载本项目 ZIP 文件并解压
2. 将文件夹复制到 Claude Code 的 skills 目录：
   - macOS/Linux：`~/.claude/skills/`
   - Windows：`%USERPROFILE%\.claude\skills\`
3. 确保文件夹结构如下：

```
~/.claude/skills/ai-detector-humanities/
├── SKILL.md
├── README.md
└── references/
    └── examples.md
```

### 验证安装

重启 Claude Code 或重新加载 skills 后输入：

```
/ai-detector-humanities
```

## 核心检测逻辑

### 底层原则：问题意识决定结构

**人类写作**：结构从问题里长出来，各部分之间是递进的因果或排除关系，拿掉任何一节整体论证会断。

**AI写作**：结构是填充出来的，各部分并列，可以被替换，说明不是从具体问题里长出来的。

大结构判断优先于逐维度打分。

### 7个检测维度

| 维度 | 权重 | 核心检测点 |
|------|------|-----------|
| 句式爆发性 | 12% | 句子长短的方差、段落是否均匀闭合 |
| 认识性标记与个人立场 | 18% | 有无真实不确定性、是否把话说死 |
| 分析深度与结构必然性 | 20% | 描述vs分析、概念外溢、文本必然性 |
| 文献引用质量 | 15% | 幻觉检测、装饰性引用识别 |
| 词汇特征 | 10% | 名词化密度、高频AI词汇 |
| 写作心理与投入均匀度 | 10% | 全文厚薄是否合理、理论是否回落到材料 |
| 语言节奏与标点个性 | 7% | 过渡词是否真实、格式残留 |

### 评级标准

| AI率 | 评级 |
|------|------|
| 0–20% | 🟢 人类写作 |
| 20–40% | 🟡 轻度AI辅助 |
| 40–60% | 🟠 显著AI特征 |
| 60–80% | 🔴 高度疑似AI |
| 80–100% | ⛔ 极高AI率 |

## 检测的AI写作模式

**大结构层面（最重要）**
- 各部分并列可替换，不是从同一问题长出来的
- 拿掉任何一节整体逻辑不会断

**段落层面**
- 每段均匀闭合，总结句压尾
- 概念推概念，不是文本逼出结论
- 理论自我增殖：连续段落无具体材料，只有概念推进

**语言层面**
- 把话说死：宣告式完成态句子（"这揭示了……""不可互相约化"）
- 格言式收尾：可以插入任何同类论文结尾
- 装饰性文献：删掉引用论点仍成立
- 概念外溢：抽象名词链不落地（"话语体系→权力结构→内在逻辑"）

**降低AI率的人类信号**
- 主动承认论证局限，且不确定性有具体对象
- 使用排除法：建立备选项逐一排除
- 大结构不对称：某部分明显更长，因为问题在那里
- 从一个具体细节撬动核心论点

## 适用范围

**适用：** 历史、哲学、文学、艺术史、社会学等本科人文课程的期末论文、课程论文

**不适用：** 理工科报告、商科文案、政府公文；研究生及以上学位论文需结合更高学术规范判断

**特别注意：** 非母语写作者（如英文写作的中国学生）存在被误判风险，需降低语言层面权重，重视内容层面判断。

## 理论来源

| 研究 | 核心发现 |
|------|---------|
| Herbold et al. (2023) *arXiv* | AI文本有更多名词化、更少话语标记和认识性标记 |
| PNAS (2025) | LLM写作有更多名词化、更少第一人称和认识性立场标记 |
| 牛津大学 (2024) | 人文AI写作"描述多于分析"，缺乏对文本形式的精确考察 |
| MDPI (2026) | 教授首要识别信号是内容层面的幻觉，而非语言风格 |
| Pangram (2025) | Burstiness对非母语写作者存在误判风险 |

## 重要说明

- 结果为参考性评估，不作为学术不端的直接证据
- 对"人写框架+AI润色"或"AI生成+人工深度修改"的混合文本识别能力有限
- 本技能检测AI代写，不将AI协同写作（人主导、AI辅助润色）视为学术不端
